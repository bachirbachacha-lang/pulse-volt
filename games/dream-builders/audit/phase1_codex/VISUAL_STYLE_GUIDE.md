# Dream Builders — Visual Style Guide

## Existing UI reference

The current UI script defines these exact colors:

| Role | RGB |
|---|---|
| Deep panel | 16, 17, 23 |
| Main panel | 22, 23, 30 |
| Raised panel | 32, 33, 42 |
| Gold | 226, 176, 70 |
| Highlight gold | 255, 214, 120 |
| Primary text | 247, 244, 236 |
| Muted text | 165, 166, 176 |
| Positive/status green | 101, 205, 145 |

The UI uses GothamBlack for display emphasis, rounded panels, thin strokes, and short easing animations. Treat this as a reference from the existing file, not a mandate to recolor unrelated systems without owner approval.

## World-facing recommendations

- Keep civic and residential architecture readable at a distance; reserve gold for trim, signs, and premium accents.
- Use high contrast for interactable objects and player-facing instructions.
- Avoid real-world brand logos on street, shop, and vehicle props.
- Props should support the polished contemporary city tone without overwhelming the playable space.
- Favor Roblox-friendly silhouettes and simple materials; keep model scale consistent with characters and doors.

## Asset presentation

Every Codex-produced prop should include one clear PNG render, a descriptive filename, and a short note with scale and triangle count. Claude decides placement, collision, and final in-world lighting.
